# ⚽ FUTGOALSHOP
### *The Ultimate Professional Football Equipment Portal*

---

## 🌟 Project Overview
**FUTGOALSHOP** is a premium, high-performance web application tailored for the football community. It combines a modern aesthetic with practical features like an interactive shop, geolocation delivery, and a seamless user interface.

---

## 🚀 Key Features

* **⚡ Dynamic Catalog:** 60+ items including professional boots, kits, and accessories.
* **📑 Smart Pagination:** High-speed navigation (20 items per page) for a better UX.
* **📍 Precision Geolocation:** Integrated **Leaflet.js** map for pinpoint delivery marking.
* **🔐 Professional Auth:** Modern login/signup forms with glassmorphism effects.
* **📱 Fully Responsive:** Optimized for everything from mobile screens to 4K monitors.
* **💳 Payment Ready:** UI integrations for Visa, Mastercard, Payme, and Click.
